# YouTube Cloud

유튜브 댓글에서 재생 타임스탬프를 찾아 해당 순간에 영상 위로 띄우는 Chrome 확장 프로그램입니다.

## 설치

1. Chrome에서 `chrome://extensions`를 엽니다.
2. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
3. `manifest.json`이 있는 이 프로젝트 폴더를 선택합니다.
4. 이미 열려 있는 유튜브 탭은 새로고침합니다. 확장 프로그램 아이콘을 눌러 설정을 열 수 있습니다.

빌드와 별도 API 키 설정 없이 Chrome 120 이상에서 사용할 수 있습니다.

## 사용

- **랜덤 위치**는 영상 안의 서로 다른 위치에 댓글을 띄웁니다. 폭이 넓은 댓글은 오른쪽 여백을 확보하도록 왼쪽에 더 자주 배치합니다.
- **고정 채팅창**은 선택한 모서리에 댓글을 쌓습니다.
- 설정에서 표시 여부, 표시 방식, 채팅창 위치, 동시 표시 개수, 표시 시간, 글자 크기, 불투명도, 작성자 이름 표시를 조절할 수 있습니다.
- 동시 표시 개수는 1~30개(기본 10개), 표시 시간은 0.1~10.0초(기본 2초)입니다.
- **표시 딜레이**는 타임스탬프 이후 댓글이 뜰 때까지의 영상 재생 시간입니다. 0.0~5.0초를 0.1초 단위로 조절할 수 있으며, 기본값은 0.2초입니다.
- 타임스탬프가 하나면 `11:30 댓글댓글`은 `댓글댓글`로, `댓글댓글 11:30 댓글`은 그대로 표시됩니다. 여러 개가 있으면 각 타임스탬프 뒤부터 다음 타임스탬프 앞까지의 문구만 해당 시점에 표시됩니다.
- 영상 재생 시간을 기준으로 댓글을 표시하고 탐색 시 화면의 댓글을 비웁니다. 광고 재생 중에는 댓글을 표시하지 않습니다.
- 재생 컨트롤이 보이면 재생바 위에 타임스탬프 댓글 분포가 표시됩니다. 봉우리가 높을수록 해당 구간에 댓글이 많이 모여 있습니다.

댓글은 유튜브 시청 페이지의 댓글 목록에서 자동으로 최대 12페이지까지 가져옵니다. 댓글란을 스크롤하거나 답글을 펼치면 추가로 화면에 로드된 댓글도 수집합니다. 자동 수집은 유튜브의 시청 페이지 내부 응답 구조에 의존하므로, 해당 구조가 바뀌면 화면에 로드된 댓글만 반영될 수 있습니다. 팝업에서 댓글 수집 상태를 확인하거나 다시 불러올 수 있습니다. 설정은 Chrome에 로컬로 저장됩니다.
