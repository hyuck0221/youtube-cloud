# YouTube Cloud

유튜브 댓글에서 재생 타임스탬프를 찾아 해당 순간에 영상 위로 띄우는 Chrome 확장 프로그램입니다.

## 설치

1. Chrome에서 `chrome://extensions`를 엽니다.
2. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
3. `manifest.json`이 있는 이 프로젝트 폴더를 선택합니다.
4. 이미 열려 있는 유튜브 탭은 새로고침합니다. 확장 프로그램 아이콘을 눌러 설정을 열 수 있습니다.

빌드와 별도 API 키 설정 없이 Chrome 120 이상에서 사용할 수 있습니다.

## 사용

- **랜덤 위치**는 영상 안의 서로 다른 위치에 댓글을 띄웁니다. 폭이 넓은 댓글은 오른쪽 여백을 확보하도록 왼쪽에 더 자주 배치합니다.
- **고정 채팅창**은 선택한 모서리에 댓글을 쌓습니다.
- 설정에서 표시 여부, 표시 방식, 채팅창 위치, 동시 표시 개수, 표시 시간, 글자 크기, 불투명도, 작성자 이름 표시를 조절할 수 있습니다.
- 동시 표시 개수는 1~30개(기본 10개), 표시 시간은 0.1~10.0초(기본 2초)입니다.
- **표시 딜레이**는 타임스탬프 이후 댓글이 뜰 때까지의 영상 재생 시간입니다. 0.0~5.0초를 0.1초 단위로 조절할 수 있으며, 기본값은 0.2초입니다.
- 타임스탬프가 하나면 `11:30 댓글댓글`은 `댓글댓글`로, `댓글댓글 11:30 댓글`은 그대로 표시됩니다. 여러 개가 있으면 각 타임스탬프 뒤부터 다음 타임스탬프 앞까지의 문구만 해당 시점에 표시됩니다.
- 영상 재생 시간을 기준으로 댓글을 표시하고 탐색 시 화면의 댓글을 비웁니다. 광고 재생 중에는 댓글을 표시하지 않습니다.
- 재생 컨트롤이 보이면 재생바 위에 타임스탬프 댓글 분포가 표시됩니다. 설정에서 그래프를 끄거나 선 그래프와 얇은 막대 그래프 중 하나를 선택할 수 있습니다. 그래프가 높을수록 해당 구간에 댓글이 많이 모여 있습니다.

유튜브가 제공하는 댓글과 답글을 다음 페이지가 없어질 때까지 가져옵니다. 최신순 목록을 사용할 수 있으면 우선 사용합니다. 최상위 댓글 목록은 다음 페이지 토큰을 받은 순서대로 읽고, 별도로 열 수 있는 답글은 동시에 가져옵니다. 동시 요청은 기본 1개이며, 전체 댓글 1만 개당 1개를 허용해 최대 10개까지 늘립니다. 확인한 타임스탬프 댓글부터 반영합니다. 유튜브가 댓글을 숨기거나 요청을 제한하면 수집 범위가 줄어들 수 있습니다. 팝업에서 전체 댓글 수 대비 진행률을 볼 수 있으며, 유튜브가 축약한 댓글 수를 제공하면 근사치로 표시합니다. 댓글란에서 직접 펼쳐 로드한 댓글도 반영됩니다. 설정은 Chrome에 로컬로 저장됩니다.

## YouTube Data API 사용

팝업의 **고급설정**에서 개인 Google Cloud 프로젝트의 API 키를 입력합니다. **연결 테스트**로 댓글 조회를 확인할 수 있으며, **YouTube Data API 사용**을 켜면 공식 API로 즉시 전환됩니다. **키 저장**으로 등록한 키를 별도로 변경할 수 있습니다. API 키는 Chrome에 로컬로 저장되며 YouTube 페이지의 스크립트에 전달하지 않습니다.

오늘 사용량은 이 브라우저에서 보낸 요청을 API 키별로 합산한 값이며, 기본 일일 한도인 10,000유닛을 기준으로 표시됩니다. 최상위 댓글 1,000개는 페이지당 100개 기준으로 최소 10유닛입니다. 프로젝트 전체 사용량과 할당량은 [Google Cloud 콘솔](https://console.cloud.google.com/apis/api/youtube.googleapis.com/quotas)에서 확인할 수 있습니다.
